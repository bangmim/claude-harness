description: 티스토리 블로그 글 작성 (writing-tistory-blog 스킬 호출)
---

`writing-tistory-blog` 스킬을 사용해서 블로그 글을 작성해주세요.

스킬은 `~/.claude/skills/writing-tistory-blog/config.md`에서 블로그 URL, 카테고리 정의, 저장 경로, 톤 예시, 제목 prefix 예시를 읽어옵니다. `config.md`가 없으면 사용자에게 `config.example.md`를 `config.md`로 복사하고 자기 블로그 정보를 채우라고 안내하세요.

사용자가 소재와 카테고리를 명시했다면 그대로 진행하고, 명시하지 않았다면 다음을 짧게 확인하세요:
- 어떤 주제인지
- 어떤 카테고리인지 (판단 애매할 때만 질문 — `config.md`에 정의된 카테고리 이름 기준)

작성 완료 후 `open {config.save_dir}` 를 실행해 Finder를 띄우고, 사용자에게 티스토리 복붙 가이드를 안내하세요.
