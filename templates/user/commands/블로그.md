description: 티스토리 블로그 글 작성 (writing-tistory-blog 스킬 호출)
---

`writing-tistory-blog` 스킬을 사용해서 블로그 글을 작성해주세요.

사용자가 소재와 카테고리를 명시했다면 그대로 진행하고, 명시하지 않았다면 다음을 짧게 확인하세요:
- 어떤 주제인지
- "사이드 프로젝트" / "개발 오답노트" 중 어느 카테고리인지 (판단 애매할 때만 질문)

작성 완료 후 반드시 `open ~/docs/blog/` 를 실행해 Finder를 띄우고, 사용자에게 티스토리 복붙 가이드를 안내하세요.
